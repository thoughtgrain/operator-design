# Library

Screens that passed an audit (`opxy/audit.md`) and that their authors have shared here. Each one is a worked reference: its contact sheet, its control mapping, its audit, and the decisions worth copying.

To add one, ask for an audit ("this is mine, does it meet the guidelines?"). If the verdict is **meets**, the entry is made from `opxy/templates/library-card.md`. Every entry carries its category from `opxy/categories.md`, and the same row goes into `opxy/catalog.json` under `library`.
