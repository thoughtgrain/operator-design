# Toro · handoff

For implementing the revised TAURUS screen in `thoughtgrain/labyrinth` → `opxy/machines/toro`. The frames in `frames/` are the target poses; `gen_frames.py` holds the exact geometry and mapping maths, so port from it rather than measuring the pictures.

## What changes in the machine

| File | Change |
| --- | --- |
| `gen_panel.py` | New node order (below). Paths 0/1 become the ecliptic: two ribbons of 32 points per edge, x 24–240 and 240–456, baseline y 204, authored in place with no transform. Joins split into short (authored 30 px) and long (authored 100 px) so uniform scale stays ≤ 2 and widths stay 0.8–2.4 px. Standing comet: 3 tapered segments (authored 14 px) and a head. Milky Way: 3 line ribbons instead of the 170-star scatter and filled band. Static field cut to 22 stars of r 1.6; grid arcs as filled 1 px ribbons in `#323232` (no open strokes). Labels: `TAURUS` 13 px, `α Aldebaran`, `ο`, `Pleiades` (moved below the cluster) at 10 px `#7D7D7D`; β/ζ labels and the RA/Dec line removed. Header cover path gets `stroke="none"`. Aphx curve for the comet: `kink = 0.4·a + 0.6·a³` (matches the engine's near-linear-then-cubic response). Segment `k` heading: `−75° ± kink · 35° · (k + 1) / 2`, alternating sign; segment length `14 · (1 + kink)`.

Fold shape: for each sample `u` across the span, `y = 204 − 11 · fold(g · sin(πu))` with `g = 1 + 7 · fold`, where `fold()` reflects at ±1, the same reflection the engine's wavefolder does. Each ribbon edge is offset ±0.9 px along the averaged normal.

## Path key policy

Paths 0 and 1 change key only when the eased fold value crosses to a new detent value. Never key on time. A note flare is a `shade` change on nodes 0 and 1, not a new key.
